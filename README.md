# VKMusic_RPC
<img width="512" height="512" alt="VMR logo" src="https://github.com/user-attachments/assets/6b92a1b8-a21a-4411-b985-c7d2716f5d06" />

Интеграция дискорда с ВК Музыкой, трек, исполнитель, обложка, кликабельная ссылка

Никакой возни со стаусом музыки в профиле, всё тянется с плеера во вкладке
который переходит вместе со страницей, кайф? абсолютный.
А ещё это единственный рабочий на момент публикации rpc для вк
благодаря принципу работы должен быть неубиваемым и легко адаптируемым
к любым обновлениям, как вк так и браузера,
из минусов - придётся ставить расширение в браузер.

## Принцип работы

Браузерное расширение считывает текущий трек со страницы VK и
передаёт его локальному Python-скрипту, который обновляет статус
через официальный локальный Rich Presence API Discord. Скрапинга VK
API, ботов VK или сторонних серверов нет — вся цепочка работает
локально: браузер, компьютер, клиент Discord.

### Приложение

Скачать `VKMusic_RPC.exe` из [Releases](../../releases) и запустить.
Иконка появится в трее. Для автозапуска с Windows — добавить ярлык в
папку автозагрузки (`Win+R` → `shell:startup`).

## Установка из исходников

### Python-скрипт

Требуется Python 3.9+ (тестировалось на 3.14).

```
pip install -r requirements.txt
python main.py
```

Консольная версия. Для фонового режима без окна консоли:

```
pip install -r requirements-tray.txt
python tray.py
```

Для запуска двойным кликом без консоли предусмотрен `start.bat`.

### Сборка exe

```
pyinstaller --onefile --noconsole --name "VKMusic_RPC" tray.py
```

Готовый файл появится в `dist/`.

### Подпись расширения для Firefox

Требуется бесплатный аккаунт на addons.mozilla.org.

```
npm install -g web-ext
cd vkrpc-extension
web-ext sign --api-key=API_ISSUER --api-secret=API_SECRET --channel=unlisted
```

Подписанный `.xpi` появится в `web-ext-artifacts/`.

### Chrome / Edge

Подписи не требует — папка `vkrpc-extension-chrome` загружается
напрямую через «Режим разработчика» → «Загрузить распакованное
расширение».

## Конфигурация

`config.txt` создаётся автоматически при первом запуске: язык
интерфейса консоли/трея (RU/EN) и опциональные маленькая иконка с
подписью для карточки статуса. На сам вид статуса в Discord (название
и исполнитель трека) язык не влияет.

## Безопасность

- Локальный сервер слушает только `127.0.0.1`, извне недоступен
- Расширение не имеет доступа ни к чему, кроме `vk.ru`/`vk.com` и
  локального адреса; исходный код открыт для проверки
- Пароли, токены и личные данные никуда не передаются
